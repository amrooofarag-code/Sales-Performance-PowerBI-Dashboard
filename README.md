# 📊 Sales Performance & Business Analytics Dashboard

An interactive Power BI dashboard designed to analyze sales performance, category revenue, and regional market distribution.

## 📸 Dashboard Preview
![Sales Dashboard](dashboard.png)

## 🔑 Key Features & Business Insights
- **Total Sales Units:** Analyzed sales volume reaching **688K units**.
- **Product Revenue Distribution:** Tracked performance across top product categories (Smartphones, Laptops, Headphones, Smartwatches, Tablets).
- **Geographic Segmentation:** Visualized regional sales distribution across key Egyptian cities (*Cairo, Alexandria, Mansoura, Tanta*).
- **Monthly Revenue Seasonality:** Monitored revenue trends month-over-month to highlight peak sales performance.

## 🛠 Tools & Tech Stack
- **Business Intelligence:** Power BI
- **Data Transformation:** Power Query
- **Calculations:** DAX Measures
